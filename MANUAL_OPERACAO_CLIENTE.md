# Manual de Operação - WJ Eventos

Este manual foi desenhado para os operadores que utilizarão o sistema **WJ Eventos** durante o evento.

## 1. Como iniciar o sistema
1. Abra o navegador (Chrome/Android) na maquininha.
2. Acesse o link do sistema: `[INSERIR-LINK-AQUI]`
3. Clique em **"Instalar App"** (se o navegador oferecer essa opção) para rodar em tela cheia como um aplicativo real.
4. O sistema solicitará o PIN do caixa. Insira o código fornecido pelo administrador.

## 2. Realizando Vendas
1. Na tela principal, você verá os botões dos produtos (Cerveja, Água, etc.).
2. **Adicionar:** Clique no botão do produto para adicionar ao carrinho. Use os botões `+` e `-` para ajustar a quantidade.
3. **Forma de Pagamento:** Selecione (Dinheiro, PIX, Débito, Crédito) na parte inferior.
4. **Finalizar:** Clique no botão verde **"FINALIZAR E IMPRIMIR"**.
5. A impressora da maquininha emitirá automaticamente a(s) ficha(s).

## 3. Em caso de problemas
- **Impressora não imprimiu:** Aguarde 5 segundos. Se não imprimir, toque no botão "Reimprimir Última Ficha" (requer PIN do supervisor).
- **Sem Internet:** O sistema continua funcionando! Faça as vendas normalmente. Quando a internet voltar, o sistema sincronizará tudo automaticamente. **Não feche o navegador enquanto o símbolo de "Sincronizando" aparecer.**
- **Erro de PIN:** Verifique se digitou os 4 dígitos corretos.
- **Maquininha travou:** Feche o app, abra novamente. Se persistir, reinicie a maquininha.
